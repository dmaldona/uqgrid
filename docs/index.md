# Welcome to UQGrid

UQGrid is a research toolkit for studying uncertainty in electric power systems. It couples steady-state power flow modeling with probabilistic analyses, continuation methods, and bifurcation diagnostics so you can explore stability margins under realistic operating scenarios.

## Documentation Map

- [SNB Module](snb.md): Saddle-node bifurcation tools, solver interface, and usage tips.

## Getting Started

```bash
pip install .[docs]
mkdocs serve
```

Open <http://127.0.0.1:8000> to browse the documentation locally.
